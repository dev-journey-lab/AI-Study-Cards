1. 容器連不到 API 三步排查順序

        
1. docker ps       -> 檢查 STATUS (Up/Exited) 與 PORTS (有無 0.0.0.0:8000->8000)
2. docker logs     -> 檢查啟動崩潰錯誤，與服務是否監聽 0.0.0.0（而非 127.0.0.1）
3. curl localhost  -> 從宿主機驗證真實 HTTP 回應，區分網路問題 vs 程式 500

      


      

        
2. 建置與金鑰安全紅線

        
• 絕不把 .env 寫進 COPY 打包進 Image：把 .env 列進 .dockerignore，啟動時再用 --env-file 或平台 Secrets 注入。

        
• 資料持久化用 Volume：容器刪除時內部寫入的檔案會一起消失，資料庫與上傳檔須掛載 Volume。
