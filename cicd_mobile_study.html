1. 本專案真實 CI／CD 管線

        
[1. 本機開發]  寫程式 + python3 -m unittest discover -s tests -v
      │  git push 開 PR
      ▼
[2. CI 自動檢查]  .github/workflows/ci.yml (permissions: contents: read)
      │  跑全站連結測試 + 守衛函式測試 + python3 -O 檢查
      │  ❌ 紅燈 -> 修好再推 | ✅ 綠燈 -> 合併回 main
      ▼
[3. CD 自動部署]  GitHub Pages 偵測 main 更新 -> 自動發布到手機網址

      


      

        
2. 測試金字塔速記

        
• 單元測試（最多、最快）：測單一函式／邊界值（毫秒級，無網路依賴）。

        
• 整合測試（適量）：測 API 路由＋資料庫或檔案互動。

        
• E2E 端對端測試（精選核心流程）：用真實瀏覽器測關鍵動線（慢但最貼近使用者）。
