1. 本機到遠端四區流程

        
Working → Staging → Local → Remote

        
工作目錄 (Working)
   │  git add <file>
   ▼
暫存區 (Staging / Index)
   │  git commit -m "feat: ..."
   ▼
本機倉庫 (Local Repository)
   │  git push origin <branch>
   ▼
遠端倉庫 (Remote / GitHub)

      


      

        
2. 團隊 Feature Branch + PR 標準流程

        
保護 main・獨立開發・審查合併

        
• Step 1 同步主幹：切回 main 並 git pull 取得最新進度。

        
• Step 2 開立分支：git switch -c feat/login，絕不直接在 main 改扣。

        
• Step 3 開發與推送：小步 add → commit → git push -u origin feat/login。

        
• Step 4 開 PR 與合併：在 GitHub 發起 Pull Request → Code Review 通過 → Merge 回 main 並刪除舊分支。

      


      

        
3. 常見出錯急救速查

        
依照「走到哪一步」決定還原指令

        
• 改壞檔案還沒 add：git restore <file>（放棄工作目錄修改）

        
• 已 add 想取消暫存：git restore --staged <file>

        
• 已 commit 但未 push：git reset --soft HEAD~1（保留修改退回暫存區）

        
• 已經 push 上共用遠端：用 git revert <commit>（新增反向提交，不改寫歷史）
