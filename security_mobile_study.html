1. 核心鐵則：前端防騙，後端守門

        
• 前端（瀏覽器）：防 XSS（用 escapeHtml / textContent + CSP）、不放 API Secret、防點擊劫持。

        
• 後端（伺服器）：每次請求必驗身分（AuthN）與資料所有權（AuthZ）、驗證輸入防 SQLi、留 Audit Log。

      


      

        
2. API 四層抗攻擊防線

        
[攻擊流量 / 正常請求]
   ▼  1. 邊緣 WAF + DDoS（如 Cloudflare 先濾惡意流量）
   ▼  2. 限流 Rate Limit（按帳號 / Token / IP 超過回 429）
   ▼  3. 認證與授權（驗 JWT + 檢查資源所有權防 IDOR）
   ▼  4. 資源保護（Body 大小上限 + Timeout + 參數驗證）

      


      

        
3. 金鑰誤推公開 GitHub 急救 SOP

        
• 第 1 秒：立刻到 API 供應商後台吊銷並重發（Revoke & Rotate）金鑰（光刪 commit 沒用）。

        
• 第 2 步：把 .env 加進 .gitignore，開啟 GitHub Secret Scanning / Push Protection。

        
• 第 3 步：設定每月消費硬上限（Billing Cap）與環境隔離（dev / prod 分開金鑰）。
