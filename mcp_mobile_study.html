1. Host & Client（發起端）

        
Claude / Antigravity / Codex / Python Host

        
• 負責管理與使用者的對話、向 MCP Server 索取工具清單（tools/list），並在模型發出工具呼叫時決定是否放行。

        
• 對應本專案 Stage 3：人工單次核准閘門（Approval Gate）設於 Host 層，人類輸入 APPROVE 後才真正執行高風險動作。

      


      

        
2. Transport（通訊傳輸協定）

        
本機 stdio / 遠端 Streamable HTTP

        
• 本機 stdio：Host 直接以子程序啟動 uv run server.py，走 stdin/stdout 交換 JSON-RPC 2.0（免開 Port、零網路暴露）。

        
• ⚠️ 重要陷阱：stdio 模式下不可用 print() 輸出除錯文字到 stdout，必須改印到 sys.stderr。

      


      

        
3. MCP Server（能力供應者）

        
FastMCP (server.py) 獨立服務

        
• 宣告三大能力：Tools（@mcp.tool() 模型主動呼叫）、Resources（@mcp.resource() 唯讀資料 URI）、Prompts（提示模板）。

        
• 安全重點：MCP 不自帶沙盒！Server 內仍須保留路徑白名單、O_DIRECTORY | O_NOFOLLOW 與 audit.jsonl 稽核紀錄。
